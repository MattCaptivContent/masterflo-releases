# MasterFlo releases

Downloads and automatic updates for MasterFlo, a private voice-dictation app for Mac.

- Download the latest version from the Releases page (MasterFlo.zip). Needs macOS 15+ on Apple Silicon.
- Once installed, MasterFlo updates itself: it shows "A new version is available" when a new release is published here.

MasterFlo is based on VoiceInk by Prakash Joshi Pax (https://github.com/Beingpax/VoiceInk) and is licensed under the GNU GPL v3. The source code for MasterFlo is available on request.
